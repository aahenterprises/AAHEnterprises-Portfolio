# AAH Enterprises

Official website and portfolio of **AAH Enterprises**, a software company offering web development, mobile apps and custom software.

**Founder & CEO:** Muhammad Awais Raza

## About this project

A modern, responsive multi-page website that introduces the company, its services and its founder. It works on phones, tablets and desktops.

## Pages

- **Home**: introduction of the Founder & CEO
- **About**: company story, mission and how we work
- **Services**: Web, Software, Mobile, iOS, SaaS, Database and Cloud
- **Projects**: our work
- **Why Choose Us**: what clients can expect from us
- **Contact**: Email, WhatsApp, Fiverr, Upwork, Facebook and Instagram

## Built with

- HTML5
- CSS3 (gradients, flexbox, grid, responsive design)
- Google Fonts (Playfair Display and Poppins)

## How to run

1. Download or clone this repository.
2. Open `index.html` in any browser.

No installation is needed.
